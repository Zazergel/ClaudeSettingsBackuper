# Claude Settings Backuper

Локальное desktop-приложение: находит проекты Claude Code, делает бекапы их
`settings.json`, позволяет просматривать и править конфиги, и безопасно
восстанавливает их.

## Что умеет

1. Сканирует выбранные папки в поисках проектов Claude Code — директорий, внутри которых есть папка `.claude`.
   Папки сканирования сохраняются между запусками.
2. Находит в каждом проекте файл настроек `.claude/settings.json`
3. Создаёт бекапы: копия файла с миллисекундной меткой —
   `settings.json.backup-<ГГГГ-ММ-ДД_ЧЧ-ММ-СС-мсс>`, можно добавить свою
   пометку: `...-мсс_до-эксперимента`. Несколько бекапов за одну секунду не
   затирают друг друга.
4. Просмотр и редактирование текущего `settings.json` и любого бекапа в
   отдельном окне: подсветка JSON, полоса прокрутки, индикатор несохранённых
   изменений; сохраняет ровно в тот файл, который открыт.
5. Восстанавливает: перезаписывает текущий `settings.json` выбранным бекапом
6. Безопасность: если у текущего файла ещё нет бекапов, перед перезаписью показывается предупреждение
   с вариантами **«Да» / «Да, но сначала сохранить текущую конфигурацию» / «Нет»**;
   удаление бекапа — только через отдельное подтверждение
7. Проекты из списка можно скрыть (наведение → «Скрыть»); вернуть —
   «Файл → Скрытые проекты» (список со прокруткой, окно растягивается)
8. Меню: «Файл» (добавить папку сканирования, обновить, скрытые проекты, выход)
   и «Справка» (о программе)

Бекапы удаляются только по явной просьбе через диалог подтверждения; перезапись
`settings.json` происходит только после проверки безопасности (п.6) и только
через единый `BackupEngine`.

## Запуск

Linux/macOS:

```bash
./gradlew run
```

Windows:

```bat
gradlew.bat run
```

Требуется JDK 21+. Тесты: `./gradlew test`.

## Разработка в IDEA

`File → Open` → папка проекта → Gradle sync → задача `run` (или `application → run`).
Стек: Kotlin 2.4 + Compose Multiplatform Desktop 1.12, Gradle 9.8, JVM 21.

## Структура

```
src/main/kotlin/
  Main.kt          окно, меню, состояние, связка панелей
  Scanner.kt       поиск проектов (.claude/settings.json) по корням сканирования
  BackupEngine.kt  бекап / список / восстановление / удаление + решение о предупреждении (R6)
  Prefs.kt         сохранение папок сканирования и скрытых проектов (java.util.prefs)
  ui/Theme.kt      тёмная тема в оранжевой гамме Claude, градиенты
  ui/Panels.kt     панели: корни, список проектов, детали, окно редактирования, диалоги
  ui/HiddenDialog.kt   возврат скрытых проектов в список
  ui/JsonEditor.kt     редактор JSON с подсветкой (VisualTransformation)
  ui/ConsentDialog.kt  предупреждение перед перезаписью
```

Сборка самодостаточного дистрибутива (когда понадобится):
задача `packageDistributionForCurrentOS` из плагина Compose — добавляется одной настройкой,
сейчас не включена намеренно.
