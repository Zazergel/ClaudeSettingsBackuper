# Claude Settings Backuper

Локальное desktop-приложение (не web): находит проекты Claude Code, делает бекапы их
`settings.json` и безопасно восстанавливает их.

## Что умеет

1. Сканирует выбранные папки в поисках проектов Claude Code — директорий, внутри которых есть папка `.claude`
2. Находит в каждом проекте файл настроек `.claude/settings.json`
3. Создаёт бекап: копия файла с добавленным расширением — `settings.json.backup-<ГГГГ-ММ-ДД_ЧЧ-ММ-СС>`
4. Восстанавливает: перезаписывает текущий `settings.json` выбранным бекапом
5. Безопасность: если у текущего файла ещё нет бекапов, перед перезаписью показывается предупреждение
   с вариантами **«Да» / «Да, но сначала сохранить текущую конфигурацию» / «Нет»**
6. Меню: «Файл» (добавить папку сканирования, обновить, выход) и «Справка» (о программе)

Приложение ничего не удаляет: бекапы только создаются, перезапись `settings.json` происходит
только после проверки безопасности (п.5) и только через единый `BackupEngine`.

## Запуск

Linux/macOS:

```bash
./gradlew run
```

Windows:

```bat
gradlew.bat run
```

Требуется JDK 21+. Тесты: `./gradlew test`.

## Разработка в IDEA

`File → Open` → папка проекта → Gradle sync → задача `run` (или `application → run`).
Стек: Kotlin 2.4 + Compose Multiplatform Desktop 1.12, Gradle 9.8, JVM 21.

## Структура

```
src/main/kotlin/
  Main.kt          окно, меню, состояние, связка панелей
  Scanner.kt       поиск проектов (.claude/settings.json) по корням сканирования
  BackupEngine.kt  бекап / список / восстановление + решение о предупреждении (R6)
  Prefs.kt         сохранение папок сканирования (java.util.prefs)
  ui/Theme.kt      тёмная тема, градиенты
  ui/Panels.kt     панели: корни, список проектов, детали, «О программе»
  ui/ConsentDialog.kt  предупреждение перед перезаписью
```

Сборка самодостаточного дистрибутива (когда понадобится):
задача `packageDistributionForCurrentOS` из плагина Compose — добавляется одной настройкой,
сейчас не включена намеренно.
